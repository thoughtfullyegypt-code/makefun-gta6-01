SOLMAR — a complete open-world crime game in a sun-soaked coastal city, built with three.js. Drive and steal cars across a 7×7 road grid with traffic and pedestrians, lose a 5-star wanted level against police cars and foot officers, fight through 5 story missions with a warehouse shootout, and save your progress. Everything is original: the city, the characters, the story, the art and the synthesised sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
